### 🥇 Intelligent Document Workflow Engine

<div align="center">
<em>LangGraph · FastAPI · Gemini API · RAG · FAISS · OCR · Vision · Python</em>
</div>

**Overview:** A multi-agent document intelligence system that ingests, understands, and reasons over unstructured documents. Combines OCR and vision models for extraction, RAG with FAISS-backed vector search for retrieval, and a LangGraph-orchestrated multi-agent pipeline for decision-making and task routing.

**Key Features**
- Multi-agent workflow orchestration with LangGraph
- Document parsing via OCR + vision-based extraction
- RAG pipeline with FAISS vector search and embeddings
- FastAPI backend for scalable, production-ready deployment

**Architecture:** `Document Input → OCR/Vision Extraction → Embedding Generation → FAISS Retrieval → LangGraph Multi-Agent Reasoning → Gemini API Response → FastAPI Output`
